# سلطع برجر 🍔🦀 - Salta3 Burger

أهلاً بيك في قاع الهامور! 😂
المشروع ده عبارة عن موقع Front-end تفاعلي (Static Website) لمطعم سلطع برجر الشهير، عملته كـ Portfolio ليا وتجربة لتطويع الـ CSS و الـ JS لعمل واجهة (UI/UX) عصرية، خفيفة، وواقعية جداً.

## فكرة البروجيكت 💡
الموقع مصمم كـ "مقلب" لذيذ وتجربة بصرية مبهرة. بيبدأ كأنه مطعم حقيقي بتقدر تطلب منه وجبات وتضيفها للسلة، وبينتهي بشاشة دفع وهمية بتكشف إن الموضوع كله مجرد Showcase للتصميم.

## الحماية والأمان (Security First) 🛡️
بما إني مهتم بمجال الـ Cyber Security، فالموقع ده مبني ليكون آمن تماماً:
* **Zero Backend:** مفيش أي قواعد بيانات أو سيرفرات خلفية، وبالتالي مفيش أي فرصة لثغرات الـ SQL Injection.
* **XSS Protection:** تم تعقيم (Sanitization) كل المدخلات اللي اليوزر بيكتبها في شاشة الدفع باستخدام دوال `escapeHTML` لتجنب أي هجمات من نوع DOM XSS.
* **Privacy:** مفيش أي بيانات شخصية بتتخزن أو بتتبعت لأي طرف تالت. كل الشغل Local Data في المتصفح.

## المميزات التقنية ✨
* **Glassmorphism & Neon Effects:** واجهة مستخدم بتعتمد على التأثيرات الزجاجية والإضاءة المودرن.
* **Fully Responsive:** متجاوب 100% مع جميع الشاشات (موبايل، تابلت، ديسكتوب).
* **Dynamic Cart:** سلة مشتريات تفاعلية بالكامل مبنية بـ Vanilla JavaScript.
* **Zero Dependencies:** الكود نظيف جداً ومبيعتمدش على أي مكتبات خارجية، مما يضمن سرعة أداء صاروخية.

## التشغيل 🛠️
ببساطة، نزل الملفات (Clone)، وافتح ملف `index.html` في أي متصفح.. أو تقدر تشوف النسخة اللايف المرفوعة على GitHub Pages مباشرة.
