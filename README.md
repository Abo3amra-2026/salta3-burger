# سلطع برجر 🦀 — موقع هزار

## طريقة الرفع على Netlify / GitHub Pages
1. حط الصور المطلوبة **جنب index.html مباشرة (في نفس الفولدر، مفيش فولدر assets)** بنفس الأسماء دي بالظبط:
   - logo.jpg
   - mascot.jpg
   - burger-classic.jpg
   - burger-double.jpg
   - burger-50layer.jpg
   - chicken-fried.jpg
   - salad.jpg
   - ketchup.jpg
   - water.jpg
2. لو أي صورة ناقصة، الموقع هيعرض إيموجي بديل مؤقت مكانها تلقائي (مفيش صور مكسورة تظهر).
3. ارفع الفولدر كله على Netlify (drag & drop) أو GitHub repo وفعّل GitHub Pages.

## ملاحظات
- الموقع صفحة واحدة (index.html) بدون أي مكتبات خارجية غير خطوط Google Fonts — سريع وآمن للاستضافة الساكنة.
- كل التقييمات والطلبات محلية في المتصفح فقط (لا يوجد سيرفر أو قاعدة بيانات) — مفيش بيانات حساسة بتتبعت لأي حد.
- دوس على أي تصنيف فوق (البرجر/فرايد تشكن/سلطات...) وهيسكرول لك تلقائي لقسم المنيو المفلتر.
- التصميم responsive بالكامل (موبايل / تابلت / لابتوب).
